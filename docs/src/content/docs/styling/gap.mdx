Gap adds spacing between the rows and columns of a flex container. The gutter argument says whether the value applies to rows, to columns, or to both.

```ts
node.setGap(Gutter.Row, 10);
node.setGap(Gutter.Column, "5%");
node.setGap(Gutter.All, 10);
```
