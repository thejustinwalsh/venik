Display controls how a node takes part in layout.

**Flex (default)**: The node is a flex container laid out by the CSS Flexible Box Model.

**None**: The node and its subtree are removed from layout and get zero size.

**Contents**: The node itself is skipped and its children are laid out as if they were children of its parent.

```ts
node.setDisplay(Display.None);
```
